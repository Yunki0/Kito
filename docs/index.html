Bientôt disponible

Android peut demander l’autorisation d’installer une application téléchargée depuis le navigateur. Kito est encore distribué en dehors du Play Store. Cette première version utilise la clé de développement du projet : si Android refuse une mise à jour, sauvegardez vos données dans Kito avant de désinstaller l’ancienne version, car sa désinstallation efface les données locales.
